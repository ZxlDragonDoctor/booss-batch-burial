# 每日自动投递设计

用户已确认继续实施：保留 Manifest V3 扩展，默认北京时间 09:30 每日运行。

## 行为
- 后台用单次 alarm 计算下次北京时间，浏览器启动或唤醒后可补执行当天任务，每天仅自动启动一次。
- 单一标签页持有任务；持久保存任务与岗位记录。任务跨页面加载恢复，浏览器重启中断的发送需人工核查。
- 仅确认平台成功提示或沟通按钮状态变化后计为已沟通；不将打招呼描述为已发送附件简历。
- 岗位先登记 pending 再点击。成功改为 confirmed；结果不明确保留 unknown 并暂停，避免盲目重发。
- 验证码、登录失效、频率限制暂停并通知，定时任务不能解除暂停；人工恢复前再次检查页面。
- 中国日期重置今日统计，不清除岗位记录；后台串行修改防止并发覆盖。
- 配置页展示定时开关、时间和最近结果，提供 JSON 导出岗位记录。

## 验证与边界
Node 内置测试覆盖北京时间跨日、每日幂等、单任务、启动确认、去重和暂停保留；本地模拟页面验证内容脚本。
浏览器关闭无法靠扩展启动；提供 Windows 任务计划脚本供安装，须指定已安装扩展的浏览器。
不绕过验证码或平台限制，不读取或复制个人浏览器登录资料。
