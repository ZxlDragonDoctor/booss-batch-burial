# BOSS 直聘海投助手 - 浏览器扩展设计文档

## 概述

本文档描述 **BOSS 海投助手** 浏览器扩展的设计方案。该扩展用于在 BOSS 直聘（zhipin.com）平台上自动化批量投递简历（海投），提供岗位筛选、地区过滤、自定义打招呼话术和智能节奏控制等功能。

**版本**: v1.0  
**创建日期**: 2026-06-09  
**技术栈**: Manifest V3 + Vanilla JS

---

│  │ Worker      │  │ - 职位列表扫描           │    │

│  │ - 启动/停止  │  │ - 点击打招呼            │    │

### 模块职责

| 模块 | 职责 |
|------|------|
| **Popup** | 一键启动/停止海投、今日投递统计、快速跳转配置页 |
| **Options Page** | 完整配置：职位关键词、地区筛选、打招呼内容、节奏设置、黑名单 |
| **Background Service Worker** | 接收 popup 启停信号、管理 content script 注入、调度定时任务、维护统计数据 |
| **Content Script** | 在 BOSS 直聘页面运行、扫描职位列表、匹配筛选条件、模拟点击操作、自动翻页 |

## 核心工作流程（Content Script）

### 流程图

```
用户打开 BOSS 直聘搜索页
        │
        ▼
Content Script 检测到页面
        │
        ▼
读取配置（关键词、地区、话术等）
        │
        ▼
┌──────────────────────────────┐
│ 扫描当前页职位列表            │
│ 对每个职位卡片:               │
│   ├─ 标题匹配关键词? ──否──→ 跳过
│   ├─ 排除关键词命中? ──是──→ 跳过
│   ├─ 地区匹配? ────────否──→ 跳过
│   ├─ 已投递/已沟通? ──是──→ 跳过
│   ├─ 黑名单命中? ──────是──→ 跳过
│   └─ 全部通过 ────────→ 加入队列
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│ 按队列顺序逐个处理:           │
│  1. 点击职位卡片              │
│  2. 等待右侧面板加载           │
│  3. 找到「打招呼」按钮        │
│  4. 点击打招呼                │
│  5. 等待发送成功确认           │
│  6. 记录统计                  │
│  7. 随机等待 5-12 秒          │
│  8. 处理下一个                │
└──────────────────────────────┘
           │
           ▼
本页所有职位处理完毕
        │
        ▼
┌──────────────────────────────┐
│ 自动翻到下一页                │
│ 重复以上流程                  │
│ (直到达到日限额或用户停止)    │
└──────────────────────────────┘
```

### 关键设计点

| 方面 | 策略 |
|------|------|
| **防检测** | 每次操作间隔随机 5-12 秒，鼠标动作模拟真实点击事件 |
| **容错** | 单个职位失败（加载失败/没找到按钮）自动跳过，不影响队列 |
| **翻页** | 检测到页面底部或「下一页」按钮，自动点击 |
| **日限额** | 达到上限后自动停止，background worker 次日零点重置计数 |
| **验证码** | 检测到验证码弹窗时自动暂停并通知用户 |
