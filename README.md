# 🚀 BOSS 海投助手

## v2.1 每日自动运行（2026-10-22）

默认北京时间每天 **09:30** 自动开始沟通。保留现有关键词、话术、间隔和每日上限。

### 在本机启用

1. Edge 打开 `edge://extensions`，找到本扩展并点击“重新加载”；未安装则开启开发者模式，选择“加载解压缩的扩展”，选择本项目根目录。
2. 打开扩展的选项，确认职位关键词、搜索入口、话术与额度；勾选“每天自动开始沟通”，保存。搜索 URL 中已有的城市等条件会保留；多个关键词目前只使用第一个作为自动打开页面的搜索词，其他关键词用于卡片标题筛选。
3. 在同一 Edge 用户配置中登录 BOSS，先手动运行并检查沟通记录。成功统计表示已确认打招呼，**不代表已发送附件简历**。
4. 本次改造已在当前 Windows 用户下安装 `BossHelperDailyBrowser` 任务，每天本地时间 **09:29** 打开 Edge 的 BOSS 职位页；当前系统为中国时区。扩展到 09:30 启动，错过时间时可当天补执行一次。

电脑需开机且用户已登录 Windows；休眠、关机或浏览器没有加载扩展时无法按点投递。验证码、登录失效、结果待核查会暂停，处理后点击“继续投递”。自动调度不会清除人工处理状态。

### 记录与恢复

- 后台将任务限定在一个标签页，岗位 ID 持久去重，重复回报不会重复计数。
- 点击前记录 `pending`；明确成功后为 `confirmed`；超时、关闭页面或中断则为 `unknown`，保留并跳过以防重发。
- 选项页可导出 JSON 沟通记录；暂停原因及最近结果显示在控制面板。
- 登录、验证码和访问频率限制均由用户处理；不保证服务端接受每次请求或每天达到额度。
- 地区、薪资、经验目前请在 BOSS 页面筛选后将完整搜索 URL 保存。扩展配置中的这些字段会保留，但不另外进行完整卡片筛选。

### Windows 任务维护

在项目目录的 PowerShell 中执行（默认 Edge，不读取或复制登录资料）：

```powershell
# 安装或调整 Windows 打开浏览器的时间；扩展中的执行时间需另行设置
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-daily-task.ps1 -Time 09:29

# 移除本项目的 Windows 任务
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-daily-task.ps1 -Remove
```

如使用 Chrome，安装脚本支持 `-BrowserPath` 指定 `chrome.exe`。任务必须启动已安装扩展并已登录的浏览器用户配置。Windows 任务使用本地时区；扩展使用北京时间。

### 开发验证与参考

`npm test` 验证后台状态机、日期调度、配置保存和模拟 BOSS 页面的内容脚本，并在临时 Edge 用户配置中加载真实扩展验证完整流程。浏览器测试使用本机 Edge。`npm run check` 检查 JavaScript 语法。测试不使用个人登录资料，也不向招聘方发送真实消息。

## ✨ 功能

- ✅ **自动扫描** — 自动扫描 BOSS 直聘职位列表
- ✅ **关键词筛选** — 按职位关键词过滤（如 Java、Python）
- ✅ **排除关键词** — 过滤实习、外包等不想要的职位
- ✅ **黑名单公司** — 排除指定公司
- ✅ **自定义打招呼** — 多条消息随机发送，支持公司名/职位名占位符
- ✅ **自动翻页** — 滚动加载更多职位，支持虚拟滚动容器
- ✅ **弹窗自动关闭** — 自动处理成功弹窗、"选择原因"反馈弹窗、"留在此页"弹窗
- ✅ **登录检测** — 自动检测登录状态，未登录时提示
- ✅ **风控检测** — 检测到风控/验证码自动暂停
- ✅ **日限额控制** — 每日投递上限，防止过度使用
- ✅ **投递节奏控制** — 可配置的随机间隔，模拟真人操作
- ✅ **运行日志** — 实时显示投递状态和诊断信息
- ✅ **多维度诊断** — 一键检测页面结构、选择器匹配、弹窗状态

## 📦 安装

### 从源码加载（开发模式）

1. 下载或克隆本仓库
2. 打开 Chrome/Edge 浏览器，进入 `chrome://extensions` / `edge://extensions`
3. 开启右上角的 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择项目根目录即可

## ⚙️ 使用说明

### 1. 配置关键词

打开扩展配置页（右键扩展图标 → 选项），设置：

- **关键词** — 如 `Java, 后端开发, Spring Boot`
- **排除关键词** — 如 `实习, 校招, 外包`
- **每日上限** — 建议 50-100 次
- **投递间隔** — 建议 18-35 秒
- **打招呼话术** — 支持多条，随机选用

### 2. 开始投递

1. 打开 BOSS 直聘 → 登录账号 → 搜索职位 → 进入职位列表
2. 点击扩展图标 → 点击 **诊断** 确认页面元素匹配
3. 确认无误后点击 **开始海投**
4. 扩展会自动扫描职位 → 筛选 → 打招呼 → 翻页 → 继续

### 3. 暂停/停止

- 弹窗中点击 **停止** 立即停止
- 遇到验证码自动暂停，完成后点击 **继续投递**
- 达到日限额自动停止

## 🔄 v2.0 主要改进

| 改进项 | 说明 |
|--------|------|
| **DOM 选择器增强** | 新增 BOSS 直聘新版 SPA 选择器（job-card-wrapper、job-primary 等） |
| **登录检测** | 自动检测登录页面，未登录时提示并停止 |
| **弹窗处理优化** | 修复 `dismissFeedbackDialog()` 遍历所有 div 的性能问题 |
| **聊天页返回优化** | 优先使用 `history.back()` 避免页面重载导致的状态丢失 |
| **风控检测增强** | 新增滑块验证码检测、文本特征检测、iframe 检测 |
| **翻页逻辑改进** | 支持虚拟滚动容器、加载更多按钮、多策略滚动 |
| **URL 监视器改进** | 降低轮询频率，新增登录检测，避免不必要的页面重载 |
| **多 Tab 处理** | 只向当前活动标签页发送启动指令，避免重复处理 |
| **黑名单过滤** | 新增黑名单公司过滤 |
| **配置校验** | 保存配置时校验间隔、日限额、话术等 |
| **输入框处理改进** | 使用原生 setter 触发 Vue 响应式更新 |
| **分块等待** | 间隔期间每秒检查风控，提前发现限制 |
