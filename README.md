# 🚀 BOSS 海投助手

> BOSS直聘 批量自动投递 Chrome 扩展（Manifest V3）

自动筛选岗位、打招呼、投递简历，支持关键词过滤、自定义打招呼内容、投递节奏控制。

## ✨ 功能

- ✅ **自动扫描** — 自动扫描 BOSS 直聘职位列表
- ✅ **关键词筛选** — 按职位关键词过滤（如 Java、Python）
- ✅ **排除关键词** — 过滤实习、外包等不想要的职位
- ✅ **自定义打招呼** — 多条消息随机发送，支持公司名/职位名占位符
- ✅ **自动翻页** — 滚动加载更多职位
- ✅ **弹窗自动关闭** — 自动处理成功弹窗、"选择原因"反馈弹窗
- ✅ **风控检测** — 检测到风控自动暂停
- ✅ **日限额控制** — 每日投递上限，防止过度使用
- ✅ **投递节奏控制** — 可配置的随机间隔，模拟真人操作
- ✅ **运行日志** — 实时显示投递状态和诊断信息

## 📦 安装

### 从源码加载（开发模式）

1. 下载或克隆本仓库
2. 打开 Chrome 浏览器，进入 `chrome://extensions`
3. 开启右上角的 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择项目根目录即可

### 打包安装（.crx）

1. 在 `chrome://extensions` 中点击 **打包扩展程序**
2. 选择项目目录，生成 `.crx` 文件
3. 拖入 Chrome 安装

## ⚙️ 使用说明

### 1. 配置关键词

打开扩展配置页（右键扩展图标 → 选项），设置：

- **关键词** — 如 `Java, 后端开发, Spring Boot`
- **排除关键词** — 如 `实习, 校招, 外包`
- **每日上限** — 建议 50-100 次
- **投递间隔** — 建议 18-35 秒

### 2. 开始投递

1. 打开 BOSS 直聘 → 搜索职位 → 进入职位列表
2. 点击扩展图标 → 点 **诊断** 确认页面元素匹配
3. 确认无误后点击 **开始海投**
4. 扩展会自动扫描职位 → 筛选 → 打招呼 → 翻页 → 继续

### 3. 暂停/停止

- 弹窗中点击 **停止** 立即停止
- 遇到验证码自动暂停
- 达到日限额自动停止

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| Chrome Extension Manifest V3 | 扩展规范 |
| Vanilla JavaScript | 所有逻辑 |
| Chrome Storage API | 配置和状态持久化 |
| MutationObserver | 实时监测弹窗 |
| DOM 属性选择器 | 匹配 Vue scoped CSS |

## ⚠️ 注意事项

- BOSS 直聘有服务器端风控，频繁操作可能触发限制
- 建议合理设置投递间隔（18-35 秒）
- 如遇到验证码，手动完成后点击 **继续投递**
- 本工具仅供学习交流使用，请合理使用
